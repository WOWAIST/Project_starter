# 프로젝트 정보 (Project Intake)

- **프로젝트 이름**: DeepRead
- **한 줄 소개**: AI 보조 학습으로 한국 개발자가 영어 기술 문서를 스스로 읽게 돕는 웹 애플리케이션
- **서비스 유형**: 웹앱
- **개발 기간**: 2개월
- **팀 규모 및 구성**: 2~3명 (풀스택)

## 3. 사용자
- **주요 타겟 사용자**: 영어 공식 문서를 읽어야 하는 주니어~미들 한국 개발자
- **사용자의 주요 페인포인트**: 미정
- **사용자가 얻게 되는 핵심 가치**: 번역기 없이 원문을 그대로 읽는 독립적 상태

## 4. 핵심 기능
1. 문서 URL/텍스트 입력 → 구간 자동 분리
2. 구간별 이해 질문 생성
3. 사용자 설명 입력 → AI 평가·피드백
4. 핵심 기술 용어 추출과 개념 설명
5. 학습 기록·독립성 지표 대시보드
